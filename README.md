# 🔤 Animacion Teksti

Animacion tipografik me **CSS dhe SVG** — teksti "Follow me" vizatohet me stroke-dasharray të animuar, me 5 shtresa ngjyrash që lëvizin në cikël të pafund.

## 🚀 Si ta hapësh

Hap `index.html` në browser — animacioni nis vetë dhe përsëritet pa fund. Nuk ka butona apo ndërveprim.
